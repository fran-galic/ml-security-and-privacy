# Security and Privacy of Machine Learning

This repository contains laboratory exercises and practical implementations developed as part of the **Security and Privacy of Machine Learning** course at the **University of Zagreb, Faculty of Electrical Engineering and Computing (FER)**.

The course explores security threats, privacy risks, and defense mechanisms in machine learning systems, including modern deep learning models and large language models (LLMs).

## Topics Covered

- Adversarial attacks and defenses (FGSM, PGD, C&W)
- Data poisoning and backdoor attacks
- Model stealing and extraction
- LLM security, prompt injection, and jailbreaking
- Privacy attacks and differential privacy
- Security and privacy in federated learning
- AI robustness, fairness, and explainability

## Repository Contents

Laboratory assignments, experiments, and implementations of selected attacks and defense techniques covered throughout the course.
